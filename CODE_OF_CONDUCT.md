# Code of Conduct

## Our commitment

We want oh-my-pi for Visual Studio to be a welcoming and constructive project for everyone who participates.

We expect contributors to:

- Be respectful and professional.
- Discuss technical disagreements in good faith.
- Focus criticism on ideas, code and decisions rather than people.
- Accept constructive feedback.
- Avoid harassment, discrimination, personal attacks and other disruptive behavior.

## Enforcement

Project maintainers are responsible for interpreting and enforcing this code of conduct. They may remove comments or contributions, restrict participation, or take other reasonable action when behavior violates these expectations.

For sensitive matters, contact the project maintainers through GitHub rather than opening a public issue.

This code of conduct applies to project spaces and interactions related to the project.
